## DAG (Directed Acyclic Graph)

### 그래프
그래프는 노드와 간선으로 구성된 자료구조

+ 노드
    - 객체나 상태를 나타냄
+ 간선
    - 노드 사이의 연결 관계를 표현
+ 방향성과 순환의 의미
    - 그래프는 방향성이 없을 수도 있고 한쪽 방향으로 연결될 수도 있다
    - 특정 노드에서 출발해 같은 노드로 돌아오는 경로가 존재하면 순환하는 그래프라고 한다

### DAG
+ DAG의 정의
    - Directed Acyclic Graph, 방향성이 있으면서 순환하지 않는 그래프를 의미
    - 연결의 방향은 정해져 있지만 한 노드에서 출발해 간선 방향을 따라가면 출발한 노드로 돌아오는 경로는 존재하지 않는 방향성 비순환 그래프를 말한다
+ 트리와의 차이
    - 트리는 노드마다 부모가 하나뿐이지만, DAG는 한 노드가 **여러 부모**를 가질 수 있다
    - 그래서 갈라졌던 흐름이 다시 합쳐지는(병합) 모양을 표현할 수 있다

### Git 커밋의 페어런트 관계
Git에서 각 커밋은 이전 커밋인 페어런트를 참조한다  
이 관계가 사슬처럼 연결되면서 커밋 간의 흐름과 변경 이력이 표현된다  

커밋로그는 일반적으로 수평이나 수직으로 표현하지만 엄밀하게 표현하자면 커밋 사이의 방향성을 화살표로 나타내는 것이 더 정확하다  
이때 화살표는 **자식 → 부모** 방향이다. 커밋은 자기 부모만 알고, 부모는 자식이 있는지 모른다

```
A ◄── B ◄── C ◄──── F    ← main
      ▲             │
      │             ▼        F는 부모가 C(첫번째), E(두번째) 두 개인 병합 커밋
      └── D ◄────── E
```

+ 페어런트 수
    - 첫 커밋(root commit): 0개
    - 일반 커밋: 1개
    - 병합 커밋: 2개 이상
+ 부모를 가리키는 표기
    - `HEAD~2`: 첫번째 부모를 따라 2단계 위 (`HEAD~1~1`과 같다)
    - `HEAD^2`: 병합 커밋의 **두번째** 부모 (위 그림에서 `F^2`는 E)

### 왜 순환이 생길 수 없는가
+ 커밋의 해시는 부모 커밋의 해시를 **포함한 내용**으로 계산된다
    - 자식을 만들려면 부모의 해시를 먼저 알아야 하므로, 부모가 나중에 생긴 자식을 가리키는 것은 불가능하다
    - 그래서 순환이 구조적으로 생길 수 없다
+ 같은 이유로 **과거 커밋을 수정할 수 없다**
    - 커밋 하나를 고치면 해시가 바뀌고, 그 커밋을 부모로 가진 모든 자식 커밋의 해시도 연쇄적으로 바뀐다
    - `rebase`·`commit --amend`가 커밋을 고치는 게 아니라 **새 커밋을 만들어 브랜치를 옮기는** 이유
    - 원래 커밋은 사라지지 않고 남아 있으며, `reflog`로 다시 찾을 수 있다

### 객체 그래프도 DAG다
커밋끼리의 연결(커밋 → 부모 커밋)뿐 아니라 커밋 안쪽의 연결(커밋 → Tree → 하위 Tree·BLOB)도 방향이 있고 순환하지 않는다  
내용이 같은 BLOB이나 Tree는 여러 커밋·여러 Tree가 함께 가리키므로, 이것도 부모가 여럿인 DAG가 된다  
즉 Git은 커밋 히스토리(가로 방향)와 각 커밋의 스냅샷 구조(세로 방향)를 모두 DAG로 관리한다

### 도달 가능성(reachability)
+ 브랜치·태그·`HEAD` 같은 참조에서 출발해 화살표를 따라 닿을 수 있는 커밋을 **도달 가능한(reachable)** 커밋이라고 한다
    - `git log`는 지정한 커밋에서 도달 가능한 커밋을 보여준다. 기본은 `HEAD`
    - `git log main..feature`는 feature에서는 도달 가능하지만 main에서는 도달 불가능한 커밋
+ 어떤 참조에서도 도달할 수 없는 커밋은 `git log`에 보이지 않는다
    - `reflog`에 기록이 남아 있는 동안은 보호되고(기본 90일, 도달 불가능한 항목은 30일), 기록이 만료된 뒤 `git gc`가 정리한다

```bash
git log --oneline --graph --all   # 모든 참조에서 도달 가능한 커밋을 그래프로
git cat-file -p HEAD              # parent 줄로 부모를 직접 확인
git rev-parse HEAD~2 HEAD^2       # 표기가 가리키는 커밋 해시
```
